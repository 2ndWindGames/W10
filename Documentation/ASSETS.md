# 리소스 출처

- 기획서 및 화면 참조: 인접 W08에 보관된 사용자 제공 공통 PPT, 28~34쪽. 원문 29쪽 이미지가 `Reference/opened-note-concept.png`다.
- 한국어 폰트: W09에서 이어받은 Noto Sans KR, SIL Open Font License. 원문은 `Assets/OpenedNote/Resources/OpenedNote/Font-LICENSE.txt`.
- SecondWindGames 스플래시: W09의 `SecondWindGamesLogo.png`를 동일 개발자 앱의 브랜드 자산으로 사용.
- 제품·내비게이션 아이콘: `OpenedIcon.cs`의 자체 UI Toolkit 벡터. 폰트 이모지나 외부 제품 사진을 사용하지 않음.
- 런처 아이콘과 스토어 그래픽: `Tools/create-store-assets.cjs`에서 생성하는 자체 SVG. 편집 가능한 원본은 `Store/Graphics/*-source.svg`.
- 스토어 스크린샷: Editor의 실제 Unity UI를 격리된 예시 데이터로 렌더링. 화면 합성 시안이 아니며 실제 Android 기기의 캡처라고 표기하지 않음.

제품 사진은 사용자가 선택한 이미지 한 장만 기기에 복사한다. 스토어 예시는 사진을 등록하지 않은 상태의 앱 기본 벡터를 사용한다.

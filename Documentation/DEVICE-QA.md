# Android 기기 인수 검사

이 문서는 실제 기기에서 실행할 절차다. 실행 결과를 기록하기 전에는 통과로 간주하지 않는다.

권장 조합: Android 8~12 중 한 기기(SAF), Android 13 이상 기기(Photo Picker/알림 권한), Android 16 기기(창 크기 및 16KB 환경 가능 시). 서명 후 동일 버전 산출물로 검사한다.

| 검사 | 기대 결과 |
| --- | --- |
| 오프라인 첫 실행 | 빈 목록, 제품 생성 가능, 네트워크 요청 없이 동작 |
| 한국어 IME로 이름·메모 입력 | 한글 조합 유지, 키보드와 스크롤 사용 가능, 저장 버튼 도달 가능 |
| 미래 개봉일 / 알림일 < 개봉일 / 24:00 | 오류 안내, 기존 기록 유지 |
| 같은 이름 두 제품 | 두 개 ID, 개봉일로 구분, 각자 수정·보관 |
| 사진 선택 취소 | 초안과 기존 사진 유지 |
| JPEG/PNG/HEIF 및 회전 사진 | 지원 형식은 올바른 회전으로 표시, 미지원은 오류 후 텍스트 저장 가능 |
| 큰 사진/지원 안 되는 파일 | 메모리 오류 없이 실패 안내, 초안 유지 |
| 사진 교체/삭제 후 재실행 | 새 상태 유지, 오래된 불필요 사진 정리 |
| 알림 권한 거절 | 기록 저장 성공, 홈/설정에 알림 꺼짐 표시 |
| 설정에서 허용/다시 차단 | 복귀 시 실제 상태 갱신, 가능한 미래 알림 재예약 |
| 가까운 미래 알림 | 지정 시각 이전에는 울리지 않음, OS 지연을 감안한 1회 알림, 탭 시 해당 제품 |
| 같은 시각 여러 제품 | 제품별 알림 구분, 한 제품 보관이 다른 제품에 영향 없음 |
| 오늘 이미 지난 시각 등록 | 오늘 확인 표시, 새 소급 알림 없음 |
| 보관/복구/날짜 수정 직후 프로세스 종료 | 재실행 자료 일치, 오래된 알림이 잘못 울리지 않음 |
| 기기 재부팅 | 미래 알림 복원, 과거 알림 발송 없음 |
| 시간대 변경/자정/수동 시각 변경 | 현지 날짜 기준 경과일과 미래 예약 갱신, 발송 이력 중복 방지 |
| 시스템 강제 종료 후 다시 열기 | 기록 유지, 미래 알림 재예약, 과거 알림 발송 없음 |
| 디스크 공간 부족 | 저장 실패 표시, 이전 저장 상태 유지, 저장 성공으로 오인하지 않음 |
| 큰 글자/360×640/분할 창/가로 창 | 화면 스크롤 가능, 저장·완료 버튼 접근 가능 |
| 화면 읽기 | 실제 TalkBack 탐색·입력·버튼 접근 검증. 미지원 결과를 문서에 기록 |
| 전체 삭제 후 종료/재실행 | 사용 중·보관함·사진·복구 파일·예약 제거, 빈 목록 |
| 앱 제거 후 재설치 | 이전 데이터 자동 복원 없음 |

추가 외부 단계: Play Console 내부 테스트, 사전 출시 보고서, 해당 개발자 계정에 요구되는 인증·테스트, IARC 설문.
